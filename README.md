# 🌐 EternaWeb

**CV professionnels · modernes · prêts à l’emploi**

EternaWeb est un service numérique créé par **Danielle Kabongo** pour aider les personnes à disposer rapidement d’un CV professionnel, clair et personnalisé.

## ✨ Offre actuelle

- **CV Starter — 14,99 €**
- **CV Boost — 29,99 €**
- **CV Premium — 59,99 €**
- **Lettre de motivation personnalisée — 7,99 €** en option

Le parcours EternaWeb est pensé pour être simple : choix de la formule → renseignement des informations → paiement sécurisé → traitement de la commande → réception du document.

Le parcours de commande utilise un paiement sécurisé. Le paiement par carte est traité par **Stripe** ; PayPal peut également être proposé selon le parcours disponible sur le site.
